## [0.1.0] - Prepared

### Added

- Initial Persian-first, RTL-first Android development build.
- Twelve offline philosophical missions across Truth, Justice, and Friendship.
- Local Compose-drawn artwork for worlds, stories, completion, empty Journal, and content-unavailable states.
- Local Room-backed mission progress, replay, and private Reflection Journal.
- Settings/Data & Privacy controls for clearing local progress.
- Accessibility, RTL, large-font, release-assembly, story-content, artwork-registry, Room-schema, and educational-review tests.
- Internal educational review reports for all twelve missions.
- Release engineering for versioning, signing, checksums, SBOM, license report, build info, and draft GitHub Releases.

### Changed

- Formalized app versioning through `version.properties`.

### Security

- Added conditional official-release signing that fails closed without complete maintainer secrets.
- Added release staging allowlist and deterministic SHA-256 checksum generation.
