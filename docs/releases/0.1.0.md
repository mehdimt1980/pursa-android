# Pursa 0.1.0 Release Notes

## Release summary

Pursa 0.1.0 is the first prepared technical release for a free, open-source, offline-first Persian Android app for philosophical inquiry. It does not claim public educational certification or store availability.

## Major features

- Persian-first RTL Android app shell.
- Three content worlds: Truth and Lying, Justice and Fairness, Friendship and Loyalty.
- Twelve offline missions with open questions, reasons, perspective-taking, counterexamples, and reflection.
- Local progress, replay, Settings/Data & Privacy, and private Reflection Journal.
- Original Compose-drawn offline artwork.

## Content inventory

- Truth: `truth_broken_vase`, `truth_group_photo`, `truth_strange_news`, `truth_friend_secret`.
- Justice: `justice_last_cake`, `justice_class_representative`, `justice_playground_rule`, `justice_team_prize`.
- Friendship: `friendship_new_friend`, `friendship_difficult_promise`, `friendship_whose_side`, `friendship_game_without_them`.

## Privacy

The app has no account, backend, analytics, advertising SDK, cloud sync, online AI, or Internet permission. Mission progress and Journal data stay local to the device.

## Accessibility

The release candidate includes RTL, large-font, contrast, touch-target, and navigation hardening. It does not claim formal accessibility certification.

## Install notes

Official GitHub release assets, once published, should include a signed APK and signed AAB. Android users installing outside an app store must understand their device's sideloading prompts and trust model.

## Verification information

The release workflow runs lint, unit tests, debug assembly, unsigned release verification, instrumentation-test APK assembly, signed APK/AAB assembly, signature verification, SBOM generation, license reporting, build-info generation, checksum generation, and release-staging allowlist validation.

## Checksums

Use `pursa-0.1.0-checksums-sha256.txt` from the same GitHub Release to verify downloaded assets.

## Known limitations

- No Google Play release is made in this phase.
- No Play App Signing enrollment exists yet.
- External P4C specialist review, child user pilot, formal accessibility certification, legal review, parent mode, teacher mode, audio, and store listing remain future work.
- The internal educational review reports are repository quality artifacts, not formal certification.
