# Educational Review

Pursa stories are reviewed as open-ended philosophical inquiry for Persian-speaking children approximately ages 8-12. This is an internal repository review process, not formal certification by a Philosophy for Children organization, child-development body, school authority, or clinical reviewer.

## Review Method

Each production mission receives one review file under `content/reviews/`. The reviewer reads the story JSON, manifest entry, artwork registry descriptor, completion copy, Journal candidate behavior, and relevant documentation before assigning a status.

Review files must use these headings:

- Metadata
- Central Philosophical Problem
- Competing Values Or Concepts
- Defensible Positions
- Conceptual Distinctions
- P4C Structure
- Perspective Quality
- Counterexample Quality
- Option Quality
- Final Reflection Quality
- Persian-Language Review
- Child-Safety Review
- Inclusion And Cultural Review
- Artwork Alignment
- Cross-Story Uniqueness
- Required Changes
- Compatibility Impact
- Final Review Status

Valid final statuses are:

- Approved
- Approved with minor editorial changes
- Approved after substantive revision
- Needs specialist review

## Production Readiness

A future story is production-ready only after stable IDs, valid JSON, manifest registration, artwork registration, philosophical review, P4C review, Persian editorial review, child-safety review, inclusion review, artwork review, accessibility review, Journal compatibility review, persistence compatibility decision, review report, review-index entry, tests, previews where applicable, debug verification, release verification, and final approval status.

## External Review Handoff

External reviewers should inspect the story JSON, the matching review report, the artwork registry scene, the app flow, completion text, and Reflection Journal behavior. They do not need to inspect Kotlin unless a runtime behavior question arises.

Suggested reviewer questions:

- Is the philosophical conflict genuine?
- Are at least two views defensible?
- Does any option reveal an intended answer?
- Is the language suitable for ages 8-12?
- Is any scenario emotionally unsafe?
- Does the image bias judgment?
- Does the ending remain open?
- Is uncertainty respected?

## Coverage Gaps

The current set covers reasons, perspective-taking, evidence, intention, consequence, rule testing, uncertainty, invisible work, loyalty, and inclusion. Future content can explore ambiguity, honest mistakes, restorative justice, equal opportunity, forgiveness, changing friendships, and healthy boundaries without adding those missions in this phase.
